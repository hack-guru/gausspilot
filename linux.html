GaussPilot für Linux

GaussPilot läuft unter Windows und Linux. Der Programmstand ist auf beiden Systemen derselbe. Nach der Installation startet GaussPilot leer mit der Ersteinrichtung.

So installieren Sie GaussPilot

  1. Archiv GaussPilot_Linux_….tar.gz entpacken.
  2. Im entpackten Ordner ein Terminal öffnen und eingeben:
    ./installieren.sh
    Alternativ: Rechtsklick auf installieren.sh → „Als Programm ausführen“.
  3. GaussPilot steht danach im Anwendungsmenü unter „Büro“, mit dem Euro-G-Symbol. Der Browser öffnet sich mit der Ersteinrichtung.

Was das Installationsskript macht

  • Es installiert nur für Ihren eigenen Benutzer, ohne Root-Rechte oder sudo.
  • Ihre Daten landen in Dokumente/GaussPilot, wie unter Windows.
  • Es prüft, ob Python 3.10 oder neuer vorhanden ist. Fehlt etwas, nennt es den passenden Befehl:
    Ubuntu, Debian, Mintsudo apt install python3 python3-venv
    Fedorasudo dnf install python3
    openSUSEsudo zypper install python3
    Arch, Manjarosudo pacman -S python
  • Beim ersten Mal lädt es die Programmbausteine aus dem Internet. Das dauert 1 bis 3 Minuten.
  • Es fragt, ob GaussPilot beim Anmelden automatisch starten soll.

Update

Neues Archiv entpacken und ./installieren.sh erneut ausführen. Ein laufendes GaussPilot wird vorher beendet, Ihre Daten bleiben erhalten.

Entfernen

~/.local/share/gausspilot/deinstallieren.sh

Auch dabei bleiben Ihre Daten in Dokumente/GaussPilot erhalten.

Gut zu wissen

Symbol in der Leiste: Unter KDE und Ubuntu erscheint es von selbst. Bei einem reinen GNOME braucht es die Erweiterung „AppIndicator and KStatusNotifierItem Support“. Ohne Symbol läuft GaussPilot trotzdem: erneut im Menü starten öffnet den Browser.

Handy-App und Firewall: Ist eine Firewall wie ufw aktiv, für die Handy-App die Ports 8766 und 8767 im Heim- oder Firmennetz freigeben:

sudo ufw allow from 192.168.0.0/16 to any port 8766,8767 proto tcp

Voraussetzungen: 64-Bit-PC (x86_64), Python 3.10 oder neuer, eine gängige Distribution. Internet brauchen Sie bei der Installation sowie für E-Mail-Versand und Updates.
